# TestoLab

Aplicativo experimental para registro de aplicações, cálculo de quantidade administrada, histórico de exames e organização de lembretes.

## Estado do projeto

Primeira etapa: protótipo web responsivo para testes no Chrome de Android.

## Princípios importantes

- O cálculo de mg é matemático: concentração (mg/mL) × volume (mL).
- Durateston é discriminada por seus quatro ésteres: propionato, fenilpropionato, isocaproato e decanoato.
- Resultados laboratoriais são registrados como informados, sem alteração automática.
- O gráfico de exames representa medições reais registradas pelo usuário.
- Não serão exibidas previsões individualizadas de testosterona em ng/dL até que exista modelo farmacocinético validado e dados suficientes.
- O protótipo web não substitui orientação médica e não recomenda doses ou mudanças de tratamento.

## Como testar

Abra `index.html` no navegador. Os dados do protótipo ficam salvos localmente no navegador do dispositivo.
